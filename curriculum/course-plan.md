# 課程計劃 — 的士及網約車綜合筆試

## 考試資料
- **考試名稱**：的士及網約車綜合筆試
- **考試語言**：繁體中文

## 考試格式（2026年新制）
| 部分 | 內容 | 題數 | 形式 | 合格標準 |
|------|------|------|------|----------|
| 甲部 | 的士及網約車營運 | 30題 | 選擇題（3-4選項） | 答對≥25題（最多錯5題） |
| 乙部 | 道路使用者守則 | 35題 | 選擇題（3選項） | 答對≥30題（最多錯5題） |
| **總計** | | **65題** | | 兩部均須合格 |
- **考試時間**：45分鐘
- **考試地點**：長沙灣政府合署運輸署筆試中心

## 課程結構（8週）

### 第一週：考試概述 + 的士營運基礎
- [ ] 第1課：考試格式介紹 + 學習策略
- [ ] 第2課：的士及網約車營運 — 基本法規與牌照制度
- [ ] 第3課：的士車隊制度 + 司機記分制

### 第二週：的士營運深入
- [ ] 第4課：的士收費規則 + 的士計程錶使用
- [ ] 第5課：乘客服務 — 拒載、揀客、濫收車資等違規行為
- [ ] 第6課：司機行為規範 — 駕駛時使用流動通訊設備等

### 第三週：地方識別（香港島 + 九龍）
- [ ] 第7課：香港島主要地點識別（醫院、旅遊景點、酒店、商場）
- [ ] 第8課：九龍主要地點識別
- [ ] 第9課：地方題練習 + 模擬測驗

### 第四週（8月26日-9月1日）：地方識別（新界 + 離島）+ 路線規劃
- [ ] 第10課：新界及離島主要地點識別
- [ ] 第11課：路線規劃 — 過海路線、隧道選擇
- [ ] 第12課：甲部綜合複習 + 模擬測驗（30題）

### 第五週：道路使用者守則（上）
- [ ] 第13課：道路標誌（警告、指示、禁止標誌）
- [ ] 第14課：道路標記（路面標記、車道線、斑馬線等）
- [ ] 第15課：交通燈號及交通警員手號

### 第六週：道路使用者守則（下）
- [ ] 第16課：速度限制 + 停車及泊車規則
- [ ] 第17課：安全駕駛實務（路口處理、切线、高速公路駕駛）
- [ ] 第18課：常見交通意外成因及預防

### 第七週：總複習
- [ ] 第19課：甲部總複習（的士及網約車營運全範圍）
- [ ] 第20課：乙部總複習（道路使用者守則全範圍）
- [ ] 第21課：模擬考試（完整65題，限時45分鐘）

### 第八週：最後衝刺
- [ ] 第22課：模擬考試檢討 + 常見錯誤分析
- [ ] 第23課：精華重點重溫 + 考試技巧
- [ ] 第24課：最後模擬考試 + 心理準備

---

## 每日學習建議
- **平日**：每課約30-45分鐘
- **週末**：複習該週內容 + 練習題
- **每日**：10分鐘快速複習（交通標誌、罰則數字等記憶性內容）
- **每週**：一次小測驗，檢視進度

## 學習資源
1. 道路使用者守則（2020年版）
2. 的士及網約車營運手冊（運輸署）
3. 香港街指南（地政總署）
4. 網上模擬試題
