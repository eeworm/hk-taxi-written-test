## 二、計程錶規則

### 法定要求
- 必須安裝及使用經運輸署批准的計程錶
- 必須每6個月覆檢一次
- 乘客必須能清楚看到收費顯示
- 嚴禁干擾或改裝

### 三個操作位置
| 位置 | 狀態 |
|------|------|
| FOR HIRE | 靜止，可供出租 |
| HIRED | 計費中（距離+時間合併計算） |
| STOPPED | 停止計費 |

### 計費機制
- **快行（車速 ≥ ~10-15 km/h）**：按距離計費（每200米跳錶）
- **慢行/停車（車速 < ~10-15 km/h）**：按時間計費（每分鐘跳錶）
- 兩個機制**互斥**，同一時刻只觸發一種，不會重疊收費

## 三、重點規則

| 規則 | 說明 |
|------|------|
| 傳統的士必須按錶收費 | 私下議價屬違法 |
| 車隊的士可預約定額收費 | 須事先協定 |
| **過海的士站** | 全港約**36個**；在過海的士站上車 → 乘客**只付$25隧道費（免回程費）** |
| 非過海的士站上車 + 過海 | 乘客付$25隧道費 + **$25回程費 = $50** |
| 目的地非海港另一方 | 毋須付回程費 |
| 偏遠地區不可收回程費 | 司機只能按錶收費 |
| 「8折的士」不合法 | 新制車隊的士的定額收費才是合法替代 |
| **電子支付（2026年4月1日起）** | 所有的士須提供≥2種電子支付：1種二維碼（支付寶/微信等）+ 1種非二維碼（八達通/信用卡等）；違者罰$5,000+監禁6個月；仍須接受現金 |

> 🚨 **過海隧道費詳解（2023年8月2日起，三隧分流首階段）**：
> - 的士三隧**劃一$25**（紅隧/東隧/西隧同價）——「分時段收費」只適用私家車同電單車，**的士全日劃一**，唔受時段影響！
> - **回程費$25**：只要**非過海的士站上車＋目的地在海港對岸**就要收（合共$50）——同司機實際有冇空車回程／對岸有冇載到客**無關**（「空車回程」只係立法原意，唔係收取條件）
> - 所以非過海的士站上車：最多$25+$25=$50，**唔係必然$50**

## 四、違規罰則

| 違規行為 | 罰則 |
|----------|------|
| 不按錶收費（濫收車費） | 初犯罰款$10,000+監禁6個月（第三級）；再犯$25,000+監禁12個月（第四級） |
| 干擾計程錶（首次） | 罰款$10,000 + 監禁6個月 |
| 干擾計程錶（再犯） | 罰款$25,000 + 監禁12個月 |
| 計程錶未經認可/印章不完好 | 罰款$10,000 + 監禁6個月 |

> 🧠 **兩級制罰則**：四項10分罪行（濫收車費、拒載、拒絕駛往指示地方、干擾計程錶）都係——初犯第三級（$10,000+監禁6個月）、再犯第四級（$25,000+監禁12個月）。

## 五、計程錶運作深入 Q&A

### 距離 ⇄ 時間切換機制

- 兩個計數器**各自累積**：距離計行駛米數，時間計慢車秒數
- **邊個先達標就邊個跳錶**，然後兩邊一齊清零重新計
- 同一時刻只觸發一種，有 debounce 防止連跳
- 理論上 edge case（199m → 慢車60秒跳 → 加速1m → 再跳）有可能發生，但現實概率極低

### 法例有冇寫清零規則？

**冇。** 法例（第374D章）只規定：
- 收費率（每200米/每分鐘幾錢）
- 計程錶須經運輸署批准
- 每6個月覆檢

清零與否的內部邏輯屬**運輸署技術審批層面**，非法例條文層面。

### 行李費：放車尾箱 vs 放車廂？

**判斷標準有兩個**：

| 位置 | 收費規則 |
|------|------|
| **車尾行李箱** | 不論大小，一律每件 **$6** |
| **車廂內** | 長+闊+高總和 **>140cm** → 每件$6；**≤140cm** → 免費 |
| **殘疾人士輔助器具** | 任何位置均**豁免** |
| **嬰兒車** | 按上述規則收費（冇豁免） |

> 🧠 **重點**：車廂內唔係全部免費！大型行李放車廂內（超過140cm）一樣要收$6。

### 偏遠地區回程費？

**不可以。** 司機不得以目的地偏遠為由加收任何費用，必須按錶收費。

### 換細車胎影響收費？

**違法。** 故意更換不合規格的輪胎以影響計程錶準確性 = 干擾計程錶。輪胎因氣溫的自然變化影響微乎其微，不構成問題。
