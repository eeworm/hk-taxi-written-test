# 第19課筆記：2026新制重點補充（行車記錄系統・記分制機制・報考實務）

> 📌 **來源**：運輸署《的士及網約車營運小冊子》（2026年8月3日生效）及《的士及網約車綜合筆試指引》（2026年8月版）。呢課補齊筆試實務同2026年新規矩，全部都係考點！

## 一、報考資格及考試實務（指引）

### 報考基本資格

| 項目 | 要求 |
|------|------|
| 駕駛執照 | 緊接申請前持有效私家車／輕型貨車**正式執照最少1年**（非經暫准期獲得）；或申請當日已完成**最少1年暫准期**並持有效正式執照 |
| 犯罪紀錄 | 緊接申請前**5年內**無觸犯第374章指定罪行（第36/36A條危險駕駛、第39/39A/39B/39C條酒駕相關、第39J/39K/39L/39O(1)/39S條毒駕相關）而被定罪 |
| 居留身份 | **香港永久性居民**或**不受逗留條件規限**之香港居民 |
| 路試 | ❌ 無須參加任何路試！筆試及格即可 |

### 及格後流程（數字必記！）

| 項目 | 限期 |
|------|------|
| 筆試及格**有效期** | **3年** |
| 申請的士正式駕駛執照 | 及格日起計**4個工作天後**（但不超過**3年**）提出 |
| 申領網約車車輛駕駛許可證 | 筆試及格後**3年內** |
| 職前課程完成日期 | 須為**申請的士正式駕駛執照日期前一年內** |

> 🧠 **捷徑**：已持有效的士正式駕駛執照嘅人 → **直接**申領網約車車輛駕駛許可證，唔使再考試！

> 🔴 **陷阱**：考生喺**考試前已被法庭判令停牌** → 考試資格**被取消**。

### 不及格重考（TD321）

- **郵寄**：TD321表格＋身份證明副本＋劃線支票 → 「運輸署 沙田中央郵政信箱79號」
- **網上**：政府一站通「網上預約駕駛考試」（需「智方便+」或數碼證書）
- ⚠️ **切勿**點選「預約重考生快期」！
- 70歲或以上申請人須附TD256體格檢驗證明書

### 查閱答錯的試題（不及格考生權利！）

| 項目 | 詳情 |
|------|------|
| 次數 | 最近一次筆試**最多查閱2次** |
| 限制 | 已取得新考期 → 新考期前**一星期內**不可查閱 |
| 地點 | 長沙灣政府合署2樓36號櫃檯（只可喺指定電腦） |
| 內容 | 只睇到**答錯嘅試題及所選答案**；可翻查備試資料，**不可抄錄/書寫** |
| 答案 | 運輸署**不會提供正確答案**，但會提示正確答案喺備試資料嘅**頁數及段落** |

## 二、行業結構與網約車營運限制

### 的士行業三類角色

| 角色 | 做咩 |
|------|------|
| **租車司機** | 向的士車主租賃的士嚟揸 |
| **車主司機** | 身兼車主與司機，部分時間把的士租予租車司機 |
| **出租車主** | 只把的士租予租車司機，自己**唔揸** |

> 🧠 的士牌照可以**個人或公司**名義持有；**牌照持有人＝登記車主**。車隊牌照**唔會取代**現有的士牌照，亦**並非必須**；車隊持牌人必須為香港註冊公司。

### 網約車營運限制

| 項目 | 規則 |
|------|------|
| 登記 | 網約車須以**個人名義**登記 |
| 人車綁定 | 只可由**該車登記車主**駕駛提供網約車載客服務 |
| 上落客 | 只可在**非限制區**及**一般停車灣**上落客 |
| 禁止 | 不得喺**封閉道路、限制區或禁區**提供載客服務 |

## 三、收據設備與司機身分確認

### 收據（2026年新例）

| 項目 | 詳情 |
|------|------|
| 的士 | **所有**的士均須安裝**收據打印設備**；乘客繳付車資後可要求收據 |
| 設備故障 | 用**預印表格手寫收據**代替 |
| 網約召喚的士 | 可透過手機App行程紀錄下載**電子收據** |
| 網約車 | 持牌平台須於行程完成後傳送**電子收據**，列明行程具體資料 |

### 司機身分確認

- 的士：司機必須喺車內**展示有效的士司機證**
- 網約車：司機開始營運前及營運期間，須按平台要求進行**人臉辨識**等程序確認身分
- 平台確認訂單時，須向乘客提供司機嘅**照片同姓名**等資料

## 四、行車記錄系統（🚨 必裝！）

政府已修訂法例，規定**所有的士必須安裝**獲運輸署審批嘅行車記錄系統：

| 組成 | 功能 |
|------|------|
| 車廂攝錄機 | 拍攝**車廂內情況並錄音** |
| 行車記錄儀 | 拍攝的士**外前方同後方視景** |
| 全球衞星導航系統（GPS） | 收集**的士位置數據** |

> 🔑 必須由**獲授權安裝人**安裝或改動。規定生效後，司機須確保：
> 1. 行車紀錄系統**正常運作**
> 2. 車廂攝錄機**不受阻擋**
> 3. 車內**當眼處張貼清晰告示**，告知乘客車廂攝錄機正在錄影

> 🧠 車隊的士另有要求：車廂內嘅**司機監察系統**須正常運作。

## 五、記分制完整機制（三層行動！）

> 🔴 記分兩年滾動期係按**干犯表列罪行的日期**計算，**唔係記分日期**！

### 第一層：記滿8分（但少於15分）

運輸署署長發出**「的士司機違例記分提示」**——列明兩年內被記分紀錄，提醒再被記分嘅後果。

### 第二層：記滿10分

發出**「強制修習的士服務改進課程通知」**：

| 項目 | 詳情 |
|------|------|
| 限期 | 通知日期起計**3個月內**自費修習及完成 |
| 違反後果 | 無合理辯解未完成 → 第2級罰款**$5,000+監禁1個月**，仲要照上堂 |
| 完成獎勵 | 通過課程考試 → 減分：**總分>3分減3分；總分≤3分全減** |

**4種不獲減分情況**（以完成課程當日計）：
1. 完成課程後**未能通過考試**
2. 根本**冇任何分數**（0分）
3. 已記總分**15分或以上**
4. **過去兩年內**曾因完成課程而**減過分**

### 第三層：記滿15分

取消駕駛的士資格：**首次停牌3個月，其後每次6個月**。被取消資格後，相關罪行嘅分數記項**全部註銷**。

## 六、記分制與網約車許可證掛鈎（互相影響！）

| 情況 | 對網約車車輛駕駛許可證嘅影響 |
|------|------------------------------|
| 被647章記分制取消的士資格期間 | **不符合**申請網約車許可證資格 |
| 已持有許可證者喺上述期間 | 許可證**暫時吊銷** |
| 被第375章（違例駕駛記分制）取消駕駛資格期間 | 許可證**無效**（無論領取先後） |
| 私家車／輕型貨車正式執照被取消 | 許可證**即予取消** |

> 🚨 **必記**：的士記分制（第647章）同違例駕駛記分制（第375章）兩種制度會**互相牽連**，影響網約車許可證！

## 七、行車前檢查清單（小冊子原文級別）

| 項目 | 檢查要點 |
|------|----------|
| 輪胎 | 氣壓足夠；坑紋環繞**外圓周3/4寬度**、深度**≥1mm**；表面無割損及外物依附 |
| 車輪螺栓 | 齊全；每次換胎後扭緊至**生產商規格** |
| 蓋/門 | 引擎蓋、行李倉蓋、油缸蓋／石油氣口蓋／充電端口蓋及車門穩固關上 |
| 車窗 | 玻璃無破裂 |
| 水撥 | 水撥膠無損壞或老化 |
| 後視鏡 | 穩固 |
| 照明 | 大燈、前燈、尾燈、煞車燈、指揮燈操作正常及清潔 |
| 油液 | 潤滑油、剎車油、燃油／石油氣**無洩漏** |
| 出發前 | 燃油／電量、剎車油、潤滑油、冷卻液**足夠** |

## 八、測驗目標

- 報考資格數字：**1年執照、5年無定罪、3年有效期、4個工作天**
- 記分制三層：**8分提示 → 10分課程（3個月・減3分）→ 15分停牌（3個月/6個月）**
- 行車記錄系統三功能：**車廂錄影錄音＋前後視景＋GPS**
- 網約車限制：**非限制區及一般停車灣**・**人車綁定**・**人臉辨識**
- 輪胎坑紋：**3/4圓周・1mm**
