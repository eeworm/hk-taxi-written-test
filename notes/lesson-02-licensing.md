# 第2課筆記：牌照制度與基本法規框架

**日期**：2026年8月5日

---

## 牌照種類

| 牌照類型 | 說明 |
|----------|------|
| 的士司機證 | 必須通過筆試 + 完成職前課程方可獲發 |
| 網約車司機證 | 通過筆試 + 完成網約車職前課程 |
| 的士車輛牌照 | 車輛本身需領牌（紅/綠/藍） |
| 網約車平台牌照 | 平台營運者需向政府申請 |

> 🚨 **重要**：持有普通私家車駕駛執照 ≠ 可以駕駛的士或網約車載客取酬。

---

## 三種的士（的士種類）

| 類型 | 顏色 | 營業範圍 |
|------|------|----------|
| 市區的士 | 🔴 紅色 | 港九新界大部分地區 |
| 新界的士 | 🟢 綠色 | 新界大部分地區 |
| 大嶼山的士 | 🔵 藍色 | 大嶼山及指定地區 |

### 重點規則：
- **紅的**範圍最大，但不能進入大嶼山南部禁區（如大澳、昂坪）
- **綠的**限新界，不可擅自進入市區
- **藍的**只在大嶼山，數量最少
- 各類的士**必須在准許範圍內營業**，越區載客屬違規

---

## 網約車規管重點

| 規則 | 說明 |
|------|------|
| 平台須領牌 | 網約車平台需政府營運牌照 |
| 司機須持證 | 需網約車司機證 |
| 必須預約 | **不可在街上兜客**或進入的士站候客 |
| 收費 | 須透過平台系統處理 |
| **兒童束縛設備** | **必須配備**（8歲以下/身高<1.35m須用兒童安全座椅） |

> 🚨 **的士 vs 網約車核心分別**：的士可在街上接客/的士站候客；網約車必須預約，不可街上兜客。
> 
> 🚨 **兒童安全**：網約車屬私家車類別，**必須**配備兒童束縛設備（罰款$230-$2,000）；的士獲**豁免**，不需配備。呢個係考試重點！

## 法律框架

| 法例 | 規管範圍 |
|------|----------|
| 《道路交通條例》（第374章） | 所有駕駛者基本規則 |
| 《道路交通（公共服務車輛）規例》（第374D章） | 的士、小巴、巴士等 |
| 《道路交通（網約車服務）規例》（依據第374章第55X條訂立） | 網約車平台及司機規管（平台牌照正式名稱：「網約車服務牌照」） |

## 捷徑提示

> 💡 有效的士駕駛執照持有人 → 可直接申請網約車駕駛許可證，毋須再次筆試或上課。
> 最有效率路線：**考筆試 → 的士職前課程 → 拿的士牌 → 直接申請網約車許可證**
