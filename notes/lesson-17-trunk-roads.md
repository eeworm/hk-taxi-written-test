# 第17課筆記：香港主要幹線道路系統

**日期**：2026年8月12日

---

## 一、幹線系統總覽

香港共有 **10條主要幹線**，分為三大走向：

| 走向 | 幹線 |
|------|------|
| **南北走向**（過海） | 1號、2號、3號 |
| **東西走向** | 4號、5號、6號、7號、8號 |
| **環迴/邊境** | 9號、10號 |

---

## 二、三條「過海幹線」（南北走向）🚨 最重要！

呢三條係路線題嘅核心，對應三條過海隧道：

### 1號幹線：香港仔 ↔ 沙田

```
香港仔 → 黃竹坑 → 香港仔隧道 → 灣仔/銅鑼灣
       → 🟥 紅隧（海底隧道）→ 紅磡 → 公主道
       → 九龍塘 → 🦁 獅子山隧道 → 沙田
```

| 路段 | 關鍵基建 |
|------|------|
| 港島段 | 香港仔隧道 |
| 過海 | **紅隧** |
| 九龍段 | 公主道、窩打老道 |
| 新界段 | **獅子山隧道** |

### 2號幹線：鰂魚涌 ↔ 馬料水

```
鰂魚涌/太古 → 東區走廊 → 🟨 東隧（東區海底隧道）
             → 觀塘繞道 → 🏔️ 大老山隧道 → 馬料水（沙田）
```

| 路段 | 關鍵基建 |
|------|------|
| 港島段 | 東區走廊 |
| 過海 | **東隧** |
| 九龍段 | 觀塘繞道 |
| 新界段 | **大老山隧道** |

### 3號幹線：西營盤 ↔ 元朗

```
西營盤/西環 → 🟩 西隧（西區海底隧道）→ 西九龍公路
             → 青葵公路 → 長青橋/隧道 → 汀九橋
             → ⛰️ 大欖隧道 → 元朗
```

| 路段 | 關鍵基建 |
|------|------|
| 港島段 | 干諾道西 |
| 過海 | **西隧** |
| 九龍段 | 西九龍公路、青葵公路 |
| 新界段 | 汀九橋、**大欖隧道** |

## 三、東西走向幹線

### 4號幹線：柴灣 ↔ 堅尼地城（港島北岸走廊）

> 🧠 即係港島北岸海傍主幹道！

```
柴灣 → 東區走廊（東廊）→ 銅鑼灣 → 告士打道
     → 夏慤道 → 干諾道中/西 → 西營盤 → 堅尼地城
```

| 別名/組成 | 途經 |
|------|------|
| 東區走廊 | 柴灣 → 銅鑼灣 |
| 告士打道 | 銅鑼灣 → 灣仔北 → 金鐘 |
| 干諾道中/西 | 中環 → 上環 → 西營盤 |

### 5號幹線：牛頭角 ↔ 荃灣（九龍中部走廊）

```
牛頭角 → 九龍灣 → 啟德隧道 → 紅磡（紅隧口）
       → 油麻地 → 荔枝角 → 葵涌 → 荃灣
```

| 關鍵路段 |
|------|
| 啟德隧道（舊機場隧道） |
| 西九龍走廊 |
| 葵涌道 |

### 7號幹線：將軍澳 ↔ 葵涌

```
將軍澳 → 將軍澳隧道 → 觀塘 → 九龍灣
       → 黃大仙 → 龍翔道 → 深水埗 → 荔枝角 → 葵涌
```

| 關鍵路段 |
|------|
| 將軍澳隧道 |
| 觀塘道 |
| **龍翔道** |
| 呈祥道 |

### 8號幹線：沙田 ↔ 赤鱲角機場

```
沙田 → 大圍 → 尖山隧道 → 長沙灣 → 昂船洲大橋
     → 青衣 → 南灣隧道 → 🌉 青馬大橋
     → 汲水門大橋 → 北大嶼山公路 → 機場
```

| 路段 | 關鍵基建 |
|------|------|
| 沙田段 | 尖山隧道、沙田嶺隧道 |
| 青衣段 | 昂船洲大橋、南灣隧道 |
| 大嶼山段 | **青馬大橋**、汲水門大橋 |

> 🧠 去機場最直接路線 = **3號幹線 → 8號幹線（青馬大橋）**

## 四、環迴及邊境幹線

### 9號幹線：新界環迴公路

```
城門隧道 → 沙田 → 馬料水 → 大埔 → 粉嶺 → 上水
          → 落馬洲 → 元朗 → 屯門 → 深井 → 荃灣（回起點）
```

| 路段 | 涵蓋 |
|------|------|
| 吐露港公路 | 沙田 → 大埔 |
| 粉嶺公路 | 大埔 → 上水 |
| 新田公路 | 上水 → 元朗 |
| 元朗公路 | 元朗 → 屯門 |
| 屯門公路 | 屯門 → 荃灣 |

### 10號幹線：深圳灣口岸 ↔ 藍地

```
深圳灣口岸 → 深圳灣公路大橋 → 港深西部公路 → 藍地
```

## 六、考試路線題必用口訣

### 過海三選一

```
港島東 + 九龍東 → 2號幹線（東隧）
港島中 + 九龍中 → 1號幹線（紅隧）
港島西 + 九龍西 → 3號幹線（西隧）
```

### 去機場

```
港島/九龍任何地方 → 搵最近嘅過海隧道（如需）
                  → 3號幹線 → 8號幹線 → 青馬大橋
                  → 北大嶼山公路 → 機場
```

### 去新界（不過海）

```
九龍中 → 沙田/大埔     → 1號幹線（獅子山隧道）
九龍東 → 沙田/馬鞍山   → 2號幹線（大老山隧道）
九龍西 → 荃灣/屯門     → 5號幹線 → 9號幹線
荃灣  → 元朗/上水      → 9號幹線（屯門公路 → 新田公路）
```
