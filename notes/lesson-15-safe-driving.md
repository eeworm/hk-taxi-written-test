**日期**：2026年8月11日

## 一、路口處理

### 冇交通燈的路口優先權

| 情況 | 誰優先？ |
|------|----------|
| 大路 vs 小路 | 大路優先 |
| 同等級路口 | 讓路給**右方**來車 |
| 有讓路線 | 讓路給大路上車輛 |
| 有STOP線 | **必須完全停定** |
| 迴旋處 | 讓路給**右方已喺迴旋處內**的車輛 |

### 迴旋處（圓環）🚨 必考！

香港靠左行駛，迴旋處內車輛**順時針**行駛。準備駛入迴旋處時：

> ✅ 必須**讓路畀右方已喺迴旋處內**嘅車輛——即係讓路畀迴旋處內嘅車流。

- ❌ 唔係「讓路畀左方」
- ❌ 唔係「先到先得」
- 🧠 記法：**「入迴旋處，讓右」**＝同一般路口「讓右方來車」同一個道理

### 轉彎規則

| 轉向 | 規則 |
|------|------|
| 右轉 | 讓路給迎面直行車 + 行人 |
| 左轉 | 讓路給橫過路口的行人 |
| 掉頭(U-turn) | **可以**（除非有禁止標誌/快速公路/隧道/需越雙白線；必須確保安全不阻礙他人） |

## 二、扒頭（超車）

### 不可扒頭的情況

- 雙白實線、路口/斑馬線附近
- 彎位/坡頂（視線受阻）
- 隧道內（除指定扒頭區）

> 🧠 **前車已打右燈準備轉彎** → 唔可以從**右方**超越（前車會轉入右方），但喺安全情況下可以**從左方超越**。

### 正確扒頭步驟

```
望鏡 → 打右燈 → 望盲點 → 加速 → 望左鏡 → 打左燈 → 返回
```

## 三、快線規則

> 🚨 **外線（最右線/快線）只供扒頭使用，扒頭後必須返回左線。長期佔用快線 = 違法！**

## 四、快速公路

### 絕對禁止

| ❌ 停車 | ❌ 倒車 | ❌ 掉頭 |
|❌ 行人 | ❌ 單車 | ❌ 學車 |
| ❌ 從中線/快線直接駛出出口 | | |

### 路肩（Hard Shoulder）🚨

| 用途 | 係唔係？ |
|------|:--:|
| 車輛**故障**或**緊急事故**時暫停 | ✅ 主要用途 |
| 供**緊急車輛**（救護車、消防車、警車）及**公務巡邏**使用 | ✅ |
| 「**分隔兩邊方向嘅車輛**」 | ❌ **錯！最常見嘅陷阱選項** |

> ⚠️ 路肩係**緊急用途**，唔係行車線、唔係分隔帶，唔可以攞嚟行車、超車或慢駛。

## 五、行車隧道規則 🚨 必考！

### 正常交通情況下

| 規則 | 內容 |
|------|------|
| **車速** | 切勿以**不足每小時25公里**嘅車速行駛（唔好慢駛阻住條隧道） |
| **燈光** | **切勿使用高燈**（遠光燈）——會反射／刺眼 |
| **響號** | **切勿響號**（隧道內迴音大，會滋擾其他駕駛者） |

> 🧠 記法：**隧道三不——「不慢過25、不開高燈、不響號」。**

### 隧道內其他禁止事項

- ❌ 掉頭、倒車
- ❌ 扒頭（除有指定扒頭區）
- ❌ 停車（除緊急或故障）

## 六、惡劣天氣

### 雨天
- 減速 + 開大燈/低燈
- 跟車距離加倍
- 🚨 駛過積水後 → **立即輕踏煞車試brake**（必考！）

### 大霧
- 開**低燈/霧燈**（不可開高燈！會反射）
- 減速 + 加長跟車距離
