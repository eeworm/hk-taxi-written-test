## 一、路口處理

### 冇交通燈的路口優先權

| 情況 | 誰優先？ |
|------|----------|
| 大路 vs 小路 | 大路優先 |
| 同等級路口 | 讓路給**右方**來車 |
| 有讓路線 | 讓路給大路上車輛 |
| 有STOP線 | **必須完全停定** |
| 迴旋處 | 讓路給**已在迴旋處內**的車輛 |

### 轉彎規則

| 轉向 | 規則 |
|------|------|
| 右轉 | 讓路給迎面直行車 + 行人 |
| 左轉 | 讓路給橫過路口的行人 |
| 掉頭(U-turn) | **可以**（除非有禁止標誌/快速公路/隧道/需越雙白線；必須確保安全不阻礙他人） |

## 二、扒頭（超車）

### 不可扒頭的情況

- 雙白實線、路口/斑馬線附近
- 彎位/坡頂（視線受阻）
- 前車已打右燈準備轉彎
- 隧道內（除指定扒頭區）

### 正確扒頭步驟

```
望鏡 → 打右燈 → 望盲點 → 加速 → 望左鏡 → 打左燈 → 返回
```

---

## 三、快線規則

> 🚨 **外線（最右線/快線）只供扒頭使用，扒頭後必須返回左線。長期佔用快線 = 違法！**

## 五、惡劣天氣

### 雨天
- 減速 + 開大燈/低燈
- 跟車距離加倍
- 🚨 駛過積水後 → **立即輕踏煞車試brake**（必考！）

### 大霧
- 開**低燈/霧燈**（不可開高燈！會反射）
- 減速 + 加長跟車距離
