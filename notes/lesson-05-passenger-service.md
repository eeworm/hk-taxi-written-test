# 第5課筆記：乘客服務 — 拒載、揀客、濫收車資等違規行為

**日期**：2026年8月6日

---

## 一、拒載（Refusing to Hire）

### 基本原則
> 的士司機在正常情況下**不得拒絕**乘客的租用要求。

### 合法 vs 非法拒載

| ✅ 合法拒載 | ❌ 非法拒載（常見） |
|-------------|---------------------|
| 超出營業範圍（綠的入市區） | 路程太短（短途） |
| 乘客要求去禁區 | 目的地太遠/太偏 |
| 乘客明顯醉酒/行為不檢 | 司機準備交更 |
| 乘客攜帶違禁品 | 目的地「唔順路」 |
| 的士已載客/暫停服務（HIRED/STOPPED） | 天氣差（落雨） |
| 過海的士站拒載非過海乘客 | 乘客太多（未超5人限額） |
| | 歧視性拒載（國籍/膚色/語言） |

---

## 二、揀客（Cherry-picking）

- **揀客** = 在多個潛在乘客之間選擇性接載
- 例：的士站排頭位但唔接第一個乘客
- 例：問完目的地後選擇唔載
- 與「拒載」常重疊，均屬違法

---

## 三、濫收車資（Overcharging）

| 行為 | 說明 |
|------|------|
| 收取超過計程錶金額 | 例：錶$85收$100 |
| 不按錶私下議價（傳統的士） | 傳統的士嚴禁議價 |
| 虛報附加費 | 無行李收行李費 |
| 重複收隧道費 | 已包在錶內又另收 |
| 唔找贖 | 故意不找續 |

> 罰則：罰款 + 監禁 + 的士司機違例記分制記分

---

## 四、行錯路 + 協商減車資（重要新考點！）

### 關鍵：邊個提出先？

| 情況 | 合法性 |
|------|--------|
| **乘客主動**要求減價 | ✅ 合法 |
| **司機主動**提出折扣 | ❌ 違法（構成「兜客」：罰$10,000 + 監禁6個月） |
| 司機故意兜路 | ❌ 違法（可被記5分） |
| 乘客拒絕按錶付足全額 | ❌ 違法（罰$3,000 + 監禁6個月） |

> 🧠 **記法**：減價可以，但必須乘客開口。司機自己開口 = 兜客 = 違法。

## 五、其他違規行為

### 兜路
- 未經乘客同意故意繞路 → ❌ 違法
- 因交通擠塞改行替代路線 → ✅ 合法（建議告知乘客）
- 乘客指示路線 → ✅ 合法

### 車廂吸煙
- ❌ 絕對禁止（受《吸煙（公眾衛生）條例》規管）

### 流動通訊設備（2026年1月25日起生效）

| 限制 | 規定 |
|------|------|
| 數量 | 車頭最多 **2部** |
| 屏幕尺寸 | 每部對角 ≤ **19cm（~7.48吋）** |
| 摺疊機 | 計1部，但攤開後 >19cm 即違法 |
| 分割畫面 | 冇規管（1部機開4個app合法） |
| 原廠內置導航 | 唔計（屬車輛內置部件） |
| 罰則 | 最高罰款 **$2,000** |

> 🎯 **三個數字必記**：2部、19cm、$2000

### 拒絕發出收據
- 乘客有權要求 → 司機必須提供

### 攜帶動物（普通寵物 vs 導盲犬）

| 動物類型 | 司機可否拒載？ | 收費 | 法例 |
|----------|:---:|------|------|
| **導盲犬**（視障人士） | ❌ 不可拒載 | 不收費 | 《殘疾歧視條例》第487章 |
| **普通寵物**（貓、狗等） | ✅ 可合法拒載 | 如接載 $5/隻 | 第374D章第42條——司機有**絕對酌情權** |

> 🧠 **記法**：普通寵物 = 司機話事；導盲犬 = 司機冇得話事

### 乘客污糟/體臭/衣衫不整 → 可否拒載？

| 車輛類型 | 可否拒載骯髒乘客？ | 法例 |
|------|:--:|------|
| **的士** | ❌ **冇明文授權** | 第374D章冇相關條文 |
| **巴士** | ✅ 有明確法定權力 | 第230A章第10(2)(d)條 |

> 的士司機只能靠「合理辯解」抗辯，須由法庭客觀判斷，門檻好高。

### 乘客體型大 → 係「拒絕運載要求人數」嗎？

**唔係。** 如果有安全/空間考慮（例如真係坐唔落），屬於「合理辯解」，合法。

| 司機話「載唔到咁多人」 | 真正原因 | 合法性 |
|------|------|:--:|
| 5人但只剩4個位 | 事實（已有乘客） | ✅ 合法 |
| 有人體型大真係坐唔落 | 安全考慮 | ✅ 合法（合理辯解） |
| 全部正常體型但拒載足數 | 想釣泥鯭 | ❌ 違法（記3分） |

### 粗口/無禮 → 會記分嗎？

**唔會。** 粗口、無禮、態度惡劣**不在**第647章11項記分罪行內。但可被投訴至運輸署/交通投訴組，車隊的士可能有內部罰則。
