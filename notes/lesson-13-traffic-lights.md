# 第13課筆記：交通燈號 + 交通警員手號

**日期**：2026年8月11日

---

## 一、基本三色燈號

| 燈號 | 含義 | 你必須 |
|------|------|--------|
| 🔴 紅色 | 停車 | 必須在停車線前停定 |
| 🔴🟡 紅+黃齊亮 | 準備開車 | **仍不可開車！** 等綠燈 |
| 🟢 綠色 | 可以前進 | 路口暢通才可前進 |
| 🟡 黃色 | 即將轉紅 | **必須停車**（除非太近無法安全停） |
| 🟢 綠色箭頭 → | 按箭頭方向前進 | 受保護轉向（對面車已停） |

---

## 二、行人過路燈

| 燈號 | 含義 |
|------|------|
| 🟢 綠色公仔亮定 | 可以開始過路 |
| 🟢 綠色公仔閃動 | **不可開始過路**，已在路上的盡快完成 |
| 🔴 紅色公仔 | 不可過路 |

### 設計原則
- 香港大部分路口採用**人車分隔設計**，同一衝突方向的車輛綠燈與行人綠公仔通常不會同時亮起
- 部分細路口/舊區路口可能有例外
- 守則仍規定：**轉彎時如有行人過路，必須讓路**（安全永遠第一）

---

## 三、交通警員手號

> 🚨 **警員手號 > 所有燈號/標誌**

| 手號 | 含義 |
|------|------|
| 🤚 單手舉起，手心向前 | **停車**（面向的車輛必須停） |
| 👉 單手伸出，手指向某車 | 指示該車輛停車 |
| 👋 手臂向身體方向擺動 | 示意車輛前進/駛近 |
| 🙆 雙臂水平伸直 | 兩側停車，另外兩側通行 |
| 👋 手臂伸出擺動 | 指示車輛轉向 |
