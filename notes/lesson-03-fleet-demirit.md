**日期**：2026年8月5日

## 第一部分：的士車隊制度（Taxi Fleet System）

### 為何引入？
- 傳統的士多為個體戶模式，服務質素參差
- 透過車隊統一管理 → 提升服務水平
- 加強與網約車平台競爭的能力

### 車隊制特點

| 特點 | 說明 |
|------|------|
| 車隊牌照 | 須向運輸署申請 |
| 統一標準 | 車齡、車型、設備有統一要求 |
| 電子支付 | 必須提供 |
| GPS定位 | 車輛須裝有定位系統 |
| 投訴機制 | 須設立正式投訴渠道 |
| 司機培訓 | 車隊統一管理司機質素及紀律 |
| 定額收費 | 可提供預約定額收費（不需按錶） |

### 🎯 車隊的士 vs 傳統的士

| | 車隊的士 | 傳統的士 |
|------|----------|----------|
| 收費方式 | 可按錶或預約定額 | **必須按錶收費** |
| 管理 | 車隊統一 | 個體/車行 |
| 街上兜客 | ✅ 可以 | ✅ 可以 |
| 電子支付 | 必須提供 | 可選 |

## 第二部分：的士司機違例記分制

### 這是2026年全新制度！

類似現有「違例駕駛記分制」，但專門針對**的士司機服務違規**。

### 常見違規行為（三級記分制）

| 記分 | 違規行為 |
|:----:|------|
| **10分** | **濫收車資、拒載**、拒絕駕駛至租用人指示地方、**干擾/損壞計程錶** |
| **5分** | **兜客**、**兜路**（未用最直接路線）、釣泥鯭（未經同意載他人）、欺騙收費/路線 |
| **3分** | **拒絕運載要求人數**、**拒絕發收據**、未將計程錶設定於記錄位置 |

> 🧠 記法：10分 = 同錢/客人直接有關嘅嚴重違規；5分 = 服務質素違規；3分 = 行政/手續違規

### ⚠️ 不在記分制內的行為（考試陷阱！）

以下行為**唔會**被的士記分制記分（但可能違反其他法例）：

| 行為 | 記分？ | 其他後果 |
|------|:--:|------|
| 粗口/無禮對待乘客 | ❌ | 可被投訴；車隊內部罰則 |
| 車廂吸煙 | ❌ | 違《吸煙條例》，罰$1,500 |
| 冇佩戴安全帶 | ❌ | 違第374章，定額罰款 |
| 車輛不潔 | ❌ | 違第374D章第44條，罰$2,000 |
| 衣著不當 | ❌ | 冇明確罰則（車隊可能有制服要求） |

> 🎯 **考試重點**：記分制只涵蓋**11項指定罪行**，唔係所有不當行為都會記分！

### 🎯 兩種記分制比較（必考！）

| | 違例駕駛記分制 | 的士司機違例記分制 |
|------|--------------|-------------------|
| **性質** | 駕駛安全 | 服務質素 |
| **例子** | 超速、衝紅燈、危險駕駛 | 拒載、濫收車資、揀客 |
| **後果** | 停牌（影響所有駕駛資格） | 吊銷的士司機證 |
| **影響私家車** | ✅ 會影響 | ❌ 不影響 |
| **法例** | 第374章 | 第647章 |

> 🚨 **必記**：兩種記分制**獨立運作**。的士記分制被扣滿分 → 只失去的士資格，仍然可以駕駛私家車！
