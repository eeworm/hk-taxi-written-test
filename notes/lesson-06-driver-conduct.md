# 第6課筆記：司機行為規範（完整版）

**日期**：2026年8月6日

---

## 一、流動通訊設備（完整版）

### 車頭放置限制（2026年1月25日起生效）

| 限制 | 規定 |
|------|------|
| 數量 | 最多 **2部** |
| 屏幕尺寸 | 每部對角 ≤ **19cm（~7.48吋）** |
| 摺疊機 | 計1部，但攤開後 > 19cm 即違法 |
| 分割畫面 | 冇規管（1機4app合法） |
| 原廠內置導航 | 唔計（屬車輛內置部件） |
| 罰則 | 最高罰款 **$2,000** |

### 行車操作限制

| 情況 | 合法？ |
|------|:--:|
| 手持手機通話 | ❌ |
| 免提通話 | ✅ |
| 行車時用手㩒Mon操作 | ❌ |
| 因操作手機引致危險駕駛 | ❌ 嚴重 |

> 兩套限制**獨立規管**：車頭放置 ≠ 行車操作，考試可能分開出題！

## 二、安全帶規定（2026年1月25日修訂）

| 對象 | 規定 | 邊個負責？ |
|------|------|:--:|
| 司機自己 | 必須佩戴 | 司機 |
| 前座乘客 | 必須佩戴 | **乘客自己**（所有乘客） |
| 後座乘客 | 如裝有安全帶則必須佩戴 | **乘客自己**（所有乘客） |
| **15歲以下乘客** | 必須佩戴 | **陪同嘅成年乘客**負責；的士司機**無責任** |
| 安全帶設備 | 必須保持可用 | **司機/車主** |

> 🚨 **2026年修訂重點**：的士車廂內**所有乘客**（包括15歲以下）唔戴安全帶 → **乘客自己**被檢控，的士司機**無法律責任**（同私家車司機唔同）！司機對15歲以下乘客嘅責任只適用於**貨車後座及特別用途車輛**（違例司機最高罰$2,000），**唔適用於的士**。
> 
> 罰則：最高罰款 **$5,000** 及監禁 **3個月**（唔屬的士記分制）

## 六、攜帶動物（重要！）

### 普通寵物 vs 導盲犬

| 動物類型 | 司機可否拒載？ | 收費 | 法例依據 |
|----------|:---:|------|------|
| **導盲犬**（視障人士） | ❌ 不可拒載 | 不收費 | 《殘疾歧視條例》第487章 |
| **普通寵物**（貓、狗等） | ✅ 可合法拒載 | 如接載，$5/隻 | 第374D章第42條——司機有**絕對酌情權** |

### 第374D章第42條

> 的士運載動物及鳥類，以及運載任何動物或鳥類所根據的條款及條件，**完全由該的士的司機酌情決定**。

- 司機如准許動物上車，可與乘客協商清潔費
- 乘客須對動物造成之損壞負責賠償（第42(2)條）

> 🧠 **記法**：普通寵物 = 司機話事（酌情權）；導盲犬 = 司機冇得話事（必須載）

## 八、電子支付（2026年4月1日起強制）🆕

| 要求 | 說明 |
|------|------|
| 最少種類 | **2種**：1種二維碼 + 1種非二維碼 |
| 二維碼例子 | 支付寶、微信支付、BoC Pay、PayMe |
| 非二維碼例子 | 八達通、信用卡、轉數快(FPS) |
| 現金 | **仍須接受**，須備≥$100找續 |
| 違規罰則 | 最高罰款**$5,000**及監禁**6個月** |
| 手續費 | 不得向乘客收取 |
| 裝置故障 | 須盡快維修或提供替代 |

> 🧠 **必記**：2026年4月1日起，係**所有**的士（唔只車隊）都要！
