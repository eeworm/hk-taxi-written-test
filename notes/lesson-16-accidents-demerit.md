# 第16課筆記：常見交通意外成因及預防 + 違例記分制

**日期**：2026年8月11日

---

## 一、五大常見意外成因

| 成因 | 預防 |
|------|------|
| 跟車太貼 | 至少2秒距離（雨天加倍） |
| 車速不當 | 按路況調節（即使未超速） |
| 酒後/藥後駕駛 | 呼氣 ≤ 22μg/100ml；血液 ≤ 50mg/100ml |
| 不小心駕駛 | 保持合理謹慎 |
| 衝紅燈/不依標誌 | 遵守所有燈號和標誌 |

---

## 二、疲勞駕駛

> 🚨 **唯一解法 = 停車休息**（開窗/咖啡/收音機只能短暫提神）

---

## 三、意外後處理

| 步驟 | 說明 |
|------|------|
| 1. 停車 | 必須！不顧而去是嚴重罪行 |
| 2. 確保安全 | 開死火燈 |
| 3. 報警 | 有人受傷 = 必須報警 |
| 4. 交換資料 | 姓名、地址、車牌、保險 |
| 5. 記錄現場 | 拍照、記錄詳情 |
| 6. 通知保險 | 盡快報告 |

### 必須報警的情況

- 有人受傷（不論輕重）
- 涉及政府車輛/財產
- 涉及動物（馬、牛、驢、騾、羊、豬、山羊）
- 對方不顧而去
- 無法就責任達成共識

---

## 四、違例駕駛記分制

| 記分 | 常見違例 |
|:----:|------|
| 3分 | 不依交通標誌 |
| **5分** | 不小心駕駛、衝紅燈 |
| **10分** | 危險駕駛、酒後駕駛 |

### 累積後果

| 累積分數 | 後果 |
|:--------:|------|
| 8分 | 運輸署發出「違例駕駛記分通知書」 |
| **10分或以上** | 🚨 收到「強制修習駕駛改進課程通知書」，須**3個月內**自費完成課程；**完成後可扣減3分** |
| **15分或以上** | 🚨 停牌（取消駕駛資格）：首次**3個月**；再犯**6個月** |

> 記分在違例**定罪日**起計 **2年後**自動取消
> 
> 🧠 **注意**：記滿15分 → 不可用課程扣減；課程扣減3分每兩年只能用一次
