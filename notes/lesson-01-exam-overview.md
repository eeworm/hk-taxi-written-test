# 第1課筆記：考試全貌與學習策略

**日期**：2026年8月5日

---

## 考試基本資料

| 項目 | 詳情 |
|------|------|
| 考試名稱 | 的士及網約車綜合筆試 |
| 考試地點 | 長沙灣政府合署運輸署筆試中心 |
| 考試形式 | 電腦化多項選擇題 |
| 時間限制 | 45分鐘（65題） |
| 語言選擇 | 繁體中文 / 簡體中文 / 英文 |
| 成績有效期 | 3年 |

## 考試結構

| 部分 | 內容 | 題數 | 形式 | 合格線 |
|------|------|------|------|--------|
| 甲部 | 的士及網約車營運 | 30題 | 3-4選項選擇題 | ≥25題（最多錯5） |
| 乙部 | 道路使用者守則 | 35題 | 3選項選擇題 | ≥30題（最多錯5） |

> 🚨 **關鍵**：兩部均須各自合格，不能靠其中一部拉分！

## 新制 vs 舊制

| 比較 | 舊制 | 2026新制 |
|------|------|----------|
| 部分 | 3部分 | **2部分** |
| 題數 | 90題 | **65題** |
| 地點路線 | 獨立乙部，大量背誦 | **融入甲部，大幅簡化** |
| 新增內容 | 無 | 車隊制、記分制、網約車規管 |

## 學習策略五大要點

1. **分散學習**：每日30-45分鐘 > 週末馬拉松
2. **主動回憶**：合上書本，試講給自己聽
3. **錯題為王**：分析錯因比背答案重要
4. **模擬實戰**：後期限時操練，習慣45分鐘壓力
5. **圖像記憶**：標誌、標記用圖像法，勿死記

## 完整領牌路徑

```
筆試合格 → 16小時職前課程 → 駕駛執照加簽(6號) → 領司機證 ✅
```

- 筆試合格後1年內須完成職前課程
- 職前課程費用約HK$1,160-$1,500
- 筆試報名費HK$510
