牌照種類

牌照類型 說明
的士司機證 必須通過筆試 + 完成職前課程方可獲發
網約車司機證 通過筆試 + 完成網約車職前課程
的士車輛牌照 車輛本身需領牌（紅/綠/藍）
網約車平台牌照 平台營運者需向政府申請

🚨 重要：持有普通私家車駕駛執照 ≠ 可以駕駛的士或網約車載客取酬。

三種的士（的士種類）

類型 顏色 營業範圍
市區的士 🔴 紅色 港九新界大部分地區
新界的士 🟢 綠色 新界大部分地區
大嶼山的士 🔵 藍色 大嶼山及指定地區

重點規則：

  • 紅的範圍最大，但不能進入大嶼山南部禁區（如大澳、昂坪）
  • 綠的限新界，不可擅自進入市區
  • 藍的只在大嶼山，數量最少
  • 各類的士必須在准許範圍內營業，越區載客屬違規

網約車規管重點

規則 說明
平台須領牌 網約車平台需政府營運牌照
司機須持證 需網約車司機證
必須預約 不可在街上兜客或進入的士站候客

五、計程錶運作深入 Q&A

距離 ⇄ 時間切換機制

  • 兩個計數器各自累積：距離計行駛米數，時間計慢車秒數
  • 邊個先達標就邊個跳錶，然後兩邊一齊清零重新計
  • 同一時刻只觸發一種，有 debounce 防止連跳
  • 理論上 edge case（199m → 慢車60秒跳 → 加速1m → 再跳）有可能發生，但現實概率極低

法例有冇寫清零規則？

冇。 法例（第374D章）只規定： - 收費率（每200米/每分鐘幾錢） - 計程錶須經運輸署批准 - 每6個月覆檢

清零與否的內部邏輯屬運輸署技術審批層面，非法例條文層面。

行李費：放車尾箱 vs 放車廂？

判斷標準有兩個：

位置 收費規則
車尾行李箱 不論大小，一律每件 $6
車廂內 長+闊+高總和 >140cm → 每件$6；≤140cm → 免費
殘疾人士輔助器具 任何位置均豁免
嬰兒車 按上述規則收費（冇豁免）

🧠 重點：車廂內唔係全部免費！大型行李放車廂內（超過140cm）一樣要收$6。

偏遠地區回程費？

不可以。 司機不得以目的地偏遠為由加收任何費用，必須按錶收費。

換細車胎影響收費？

違法。 故意更換不合規格的輪胎以影響計程錶準確性 = 干擾計程錶。輪胎因氣溫的自然變化影響微乎其微，不構成問題。

第18課筆記：交通標誌分類（模擬考三錯題補強）

日期：2026年8月13日

一、點解要學呢課？

模擬考三（64/65）唯一錯題：讓路標誌分類。呢課專攻標誌分類陷阱。

二、標誌四大類別

類別 特徵 功能 例子
警告標誌 三角形・紅邊白底・尖端向上 預告前方有危險 急彎、道路收窄、前面有學校
禁制標誌 圓形・紅邊 唔准做 不准泊車、不准進入、不准掉頭、車速限制
指示標誌 圓形・藍底白圖案 必須做/可以做的事 只准直行、單程路
資訊標誌 長方形・各色 提供資料 泊車處、隧道入口

三、黃金原則

🚨 功能決定分類，唔係形狀決定！

四、兩大例外（必考陷阱！）

標誌 形狀 分類
讓路（讓路給大路上的車輛） 倒三角形＋紅邊 限制標誌（禁制性）——唔係警告、唔係指示！
停車 STOP 八角形 限制標誌（禁制性）

點解咁多人錯？官方守則：「發出指令的交通標誌」稱為「限制標誌」（告知規定、禁止或限制，分「強制」或「禁制」性）。讓路同停車都係指令你行動嘅標誌，屬限制標誌——紅邊＝禁制性。形狀特別（八角形／倒三角）只係為咗遠距離都認得，分類跟功能行，唔跟形狀。

分清楚呢幾塊！

  • 「讓路」標誌本身（倒三角・紅邊）→ 限制標誌（禁制性）
  • 「停車」STOP（八角形）→ 限制標誌（禁制性）
  • 「前面有讓路標誌」預告牌（正三角形）→ 警告標誌

五、考試規律

🔑 凡係 「前面有……」 開頭嘅標誌 → 一定係警告標誌！

  • 前面有急彎 → 警告
  • 前面有迴旋處 → 警告
  • 前面有學校 → 警告
  • 前面有讓路/停車標誌 → 警告（預告牌，唔係讓路/停車本體）

六、記憶口訣

  • 🔺 三角形尖向上 → 警告（「小心呀！」）
  • ⭕ 圓形紅邊 → 禁制（「唔准！」）
  • 🔵 圓形藍底 → 指示（「必須做！」）
  • ⬜ 長方形 → 資訊（「話你知」）

一、運輸署官方路線題（必做！）

🚨 官方例題一

由西灣河嘉亨灣 → 旺角拔萃男書院（正常交通，不考慮隧道費）

選項： - A. 經東區海底隧道、觀塘道、龍翔道及竹園道 - B. 經告士打道、紅磡海底隧道及公主道 ✅ - C. 經中環灣仔繞道、干諾道中、西區海底隧道、西九龍公路及麗翔道

🧠 解說：嘉亨灣（西灣河）是港島東，但拔萃男書院（旺角/九龍中）最直接是紅隧，非東隧。因為男書院在九龍中（旺角火車站附近），紅隧出口 → 公主道 → 窩打老道 → 亞皆老街最直接。

🚨 官方例題一變體

同一路程，但紅隧港島入口發生嚴重交通意外，哪條路線最直接？

  • A. 經東區海底隧道、觀塘道、龍翔道及竹園道 ✅
  • B. 經告士打道、紅磡海底隧道及公主道
  • C. 經中環灣仔繞道、干諾道中、西區海底隧道、西九龍公路及麗翔道

🧠 考點：紅隧受阻 → 改行東隧！呢條考你應變能力。

🚨 官方例題二

由荃灣悅來酒店 → 上環港澳碼頭（正常交通，不考慮隧道費）

選項： - A. 經青葵公路、西九龍公路及西區海底隧道 ✅ - B. 經青衣南橋、昂船洲大橋、青沙公路、西九龍公路及西區海底隧道 - C. 經龍翔道、竹園道、窩打老道、公主道、紅磡海底隧道及告士打道

🧠 解說：荃灣（新界西） → 上環（港島西） = 西隧！選項B繞去青衣南橋/昂船洲太迂迴，選項C繞去紅隧完全錯方向。

六、易錯題精選（來自考生常見錯誤統計）

Q1：紅的能否進入大嶼山？ - 不能進入大嶼山南部禁區（如大澳、昂坪） - 但可經青嶼幹線到機場/東涌/迪士尼

Q2：綠的可否進入尖沙咀？ - 不可以。綠的營業範圍限新界，尖沙咀屬市區。

Q3：的士司機證必須放在哪裡？ - 車廂內乘客可見的位置

Q4：的士站排頭位的士，乘客上車前司機問目的地後拒載，是否合法？ - 不合法。這是典型的揀客行為。

Q5：的士在紅隧收費廣場，乘客付了隧道費後司機有冇責任給收據？ - 有。乘客要求的士收據，司機必須提供。

Q6：車輛駛過的士站時，能否在的士站範圍內停車上落客？ - 不可以。的士站是的士專用的。

Q7：的士車頂的「TAXI」燈箱在什麼狀態下必須亮著？ - 的士可供出租時（FOR HIRE狀態）

Q8：以下哪項是正確的行李收費？ - 放車尾箱的行李每件$6（不論大小） - 放車廂內長闊高總和超過140cm → 每件$6；≤140cm → 免費 - 輪椅、拐杖不收費 ✅（殘疾人士輔助器具） - 嬰兒車按上述標準收費（冇豁免） - 手抱寵物不收費？錯！寵物每隻$5，不論手抱與否

Q9：的士計程錶上顯示的附加費（EXTRAS）包括什麼？ - 行李費、寵物費、隧道費等。不包括司機自定的任何費用。

Q10：下列哪項不是乘客的權利？ - 要求開/關空調 ✅（是權利） - 要求開/關窗 ✅（是權利） - 要求司機超速 ❌（不是權利！）
