答題技巧：否定式問題（實戰提醒）⚠️

真實考試經常有反問（否定式）題目，一唔小心就會「見到熟悉嘅字就撳」，答咗相反嘅答案。

常見問法

問法 你要搵嘅係
「下列哪一項不正確？」 錯嘅選項
「以下哪項唔係……？」 唔符合嘅選項
「以下哪項不應……？」 唔應該做嘅事

選項陷阱

  • 「全部不正確」／「全部正確」／「以上皆是」 都係常見選項——唔好因為「好似冇一個完全對」就當佢係陷阱，要逐個核對。
  • 有時三個選項全部都係對嘅陳述，正確答案就係「全部正確」；反之亦然。

實戰做法 ✅

  1. 圈住問題入面嘅「不／唔／非／錯誤」字眼，答之前再讀一次問題
  2. 每個選項打 ✔／✘，唔好靠關鍵字配對
  3. 遇到「全部……」，逐個選項獨立判斷先，最後才睇「全部」呢個選項
  4. 唔肯定就先跳過，做完返轉頭——否定式題目特別容易睇漏眼

二、計程錶規則

法定要求

  • 必須安裝及使用經運輸署批准的計程錶
  • 必須每6個月覆檢一次
  • 乘客必須能清楚看到收費顯示
  • 嚴禁干擾或改裝

三個操作位置

位置 狀態
FOR HIRE 靜止，可供出租
HIRED 計費中（距離+時間合併計算）

計費機制

  • 快行（車速 ≥ ~10-15 km/h）：按距離計費（每200米跳錶）
  • 慢行/停車（車速 < ~10-15 km/h）：按時間計費（每分鐘跳錶）

五、計程錶運作深入 Q&A

距離 ⇄ 時間切換機制

  • 兩個計數器各自累積：距離計行駛米數，時間計慢車秒數
  • 邊個先達標就邊個跳錶，然後兩邊一齊清零重新計
  • 同一時刻只觸發一種，有 debounce 防止連跳
  • 理論上 edge case（199m → 慢車60秒跳 → 加速1m → 再跳）有可能發生，但現實概率極低

法例有冇寫清零規則？

冇。 法例（第374D章）只規定： - 收費率（每200米/每分鐘幾錢） - 計程錶須經運輸署批准 - 每6個月覆檢

清零與否的內部邏輯屬運輸署技術審批層面，非法例條文層面。

行李費：放車尾箱 vs 放車廂？

判斷標準有兩個：

位置 收費規則
車尾行李箱 不論大小，一律每件 $6
車廂內 長+闊+高總和 >140cm → 每件$6；≤140cm → 免費
殘疾人士輔助器具 任何位置均豁免
嬰兒車 按上述規則收費（冇豁免）

🧠 重點：車廂內唔係全部免費！大型行李放車廂內（超過140cm）一樣要收$6。

偏遠地區回程費？

不可以。 司機不得以目的地偏遠為由加收任何費用，必須按錶收費。

換細車胎影響收費？

違法。 故意更換不合規格的輪胎以影響計程錶準確性 = 干擾計程錶。輪胎因氣溫的自然變化影響微乎其微，不構成問題。

一、拒載（Refusing to Hire）

基本原則

的士司機在正常情況下不得拒絕乘客的租用要求。

合法 vs 非法拒載

✅ 合法拒載 ❌ 非法拒載（常見）
超出營業範圍（綠的入市區） 路程太短（短途）
乘客要求去禁區 目的地太遠/太偏
乘客明顯醉酒/行為不檢 司機準備交更
乘客攜帶違禁品 目的地「唔順路」
的士已載客/暫停服務（HIRED/STOPPED） 天氣差（落雨）
過海的士站拒載非過海乘客 乘客太多（未超該車法定座位上限）
歧視性拒載（國籍/膚色/語言）

🧠 的士最高乘客座位數目為6人（2023年修例由5人增至6人，6座車款毋須再改裝減座）；每部的士車頭及車尾嘅綠底白字字牌顯示該車嘅法定座位數目，超載即屬違法。

二、揀客（Cherry-picking）

  • 揀客 = 在多個潛在乘客之間選擇性接載
  • 例：的士站排頭位但唔接第一個乘客
  • 例：問完目的地後選擇唔載
  • 與「拒載」常重疊，均屬違法

行為 說明

不按錶私下議價（傳統的士） 傳統的士嚴禁議價

罰則：罰款 + 監禁 + 的士司機違例記分制記分

四、行錯路 + 協商減車資（重要考點！）

關鍵：唔係「邊個提出」，而係有冇「招徠誘使乘客使用該車」

《道路交通（公共服務車輛）規例》（第374D章）兩條條文要分清楚：

條文 內容
第47(2)條（濫收車資） 只禁止收取高於附表5嘅車費 → 冇條文禁止減收車資
第40條（兜客） 司機、其代表或看來代表司機行事的人，不得以任何方式吸引或致力吸引任何人，以誘使其使用該車輛（「提供車費折扣」係法例明文舉例）
罰則（第57(4)條） 兜客：罰$10,000 + 監禁6個月（記分制5分）
情況 合法性
行錯路後，司機主動減收車資（乘客已在車上） ✅ 唔違法（冇誘使任何人「使用該車」；減收本身亦非罪行）
乘客主動要求減價 ✅ 法例無禁止乘客提出；司機可答應亦可拒絕
司機以折扣招徠（街頭／的士站／派卡片／app）誘使乘客搭車 ❌ 違法 =「兜客」：罰$10,000 + 監禁6個月 + 記5分
司機故意兜路 ❌ 違法（第37(d)條：罰$10,000 + 監禁6個月 + 記5分）
乘客拒絕按錶付足全額 ❌ 違法（罰$3,000 + 監禁6個月）

🧠 記法：關鍵唔係「邊個開口」，而係有冇用折扣去招客（誘使未上車嘅人搭你架車）。 ⚠️ 但街頭截乘（非預約）必須按錶收費，唔可以議價；車隊網約／「包車」行程則可協定車費。

二、行人過路燈

燈號 含義
🟢 綠色公仔亮定 可以開始過路
🟢 綠色公仔閃動 不可開始過路，已在路上的盡快完成
🔴 紅色公仔 不可過路

設計原則

  • 香港大部分路口採用人車分隔設計，同一衝突方向的車輛綠燈與行人綠公仔通常不會同時亮起
  • 部分細路口/舊區路口可能有例外
  • 守則仍規定：轉彎時如有行人過路，必須讓路（安全永遠第一）

四、斜坡停車：波箱／手掣次序 🚨 必考！

落斜（下坡）泊車

波箱 正確做法
自動波（自排） 先拉緊電子手掣／手掣鎖定車輛 → 最後才入 P 波
手波（手排） 入 後波（倒車擋）

⚠️ 點解要先拉手掣、後入 P 波？ 若先入 P 波，成架車嘅重量會由 P 波嘅鎖止機構（parking pawl）承受，落斜時容易磨損甚至卡死；正確次序係由手掣煞住架車，P 波只作後備。

上斜（上坡）停車下車（例如搬貨）

必須做齊以下四項：

  1. 拉緊手掣
  2. 熄火
  3. 入波：手波車入 1 波；自動波車入 P 波
  4. 扭軚 + 落楔：前輪扭向右邊（上斜有壆＝扭外），並喺後輪放置車輪楔塊（車轆磚）防止溜後

轉向 規則

二、扒頭（超車）

🚨 從邊一方扒頭？只可從右方！

《道路使用者守則》原文：

「只可從右方超車。 切勿駛入左線超車，也不可利用路肩超車。」（分隔車路）

「切記只可在前車的右面超車。」

香港靠左行駛，所以超車（扒頭）一律從右方（外側）進行。

  • ❌ 唔可以從左方超車（左邊係內側，其他車可能喺度）
  • ❌ 唔可以利用路肩超車
  • ✅ 唯一例外：前車已打右燈準備轉彎 → 呢個情況下可以喺安全時從左方越過（因為前車會轉去右邊）

不可扒頭的情況

  • 雙白實線、路口/斑馬線附近
  • 彎位/坡頂（視線受阻）
  • 隧道內（除指定扒頭區）

🧠 要分清楚：一般規則 = 從右方超車；前車打右燈轉彎 = 例外可以從左方越過。 考試陷阱通常係掉轉呢兩句（例如「如不能從左方超車，才從右方超」——錯）。

正確扒頭步驟

望鏡 → 打右燈 → 望盲點 → 加速 → 望左鏡 → 打左燈 → 返回

一、點解要學呢課？

二、標誌四大類別

類別 特徵 功能 例子
警告標誌 三角形・紅邊白底・尖端向上 預告前方有危險 急彎、道路收窄、前面有學校
禁制標誌 圓形・紅邊 唔准做 不准泊車、不准進入、不准掉頭、車速限制
指示標誌 圓形・藍底白圖案 必須做/可以做的事 只准直行、單程路

三、黃金原則

🚨 功能決定分類，唔係形狀決定！

四、兩大例外（必考陷阱！）

標誌 形狀 分類
讓路（讓路給大路上的車輛） 倒三角形＋紅邊 限制標誌（禁制性）——唔係警告、唔係指示！
停車 STOP 八角形 限制標誌（禁制性）

點解咁多人錯？官方守則：「發出指令的交通標誌」稱為「限制標誌」（告知規定、禁止或限制，分「強制」或「禁制」性）。讓路同停車都係指令你行動嘅標誌，屬限制標誌——紅邊＝禁制性。形狀特別（八角形／倒三角）只係為咗遠距離都認得，分類跟功能行，唔跟形狀。

分清楚呢幾塊！

  • 「讓路」標誌本身（倒三角・紅邊）→ 限制標誌（禁制性）
  • 「停車」STOP（八角形）→ 限制標誌（禁制性）
  • 「前面有讓路標誌」預告牌（正三角形）→ 警告標誌

五、考試規律

🔑 凡係 「前面有……」 開頭嘅標誌 → 一定係警告標誌！

  • 前面有急彎 → 警告
  • 前面有迴旋處 → 警告
  • 前面有學校 → 警告
  • 前面有讓路/停車標誌 → 警告（預告牌，唔係讓路/停車本體）

六、記憶口訣

  • 🔺 三角形尖向上 → 警告（「小心呀！」）
  • ⭕ 圓形紅邊 → 禁制（「唔准！」）
  • 🔵 圓形藍底 → 指示（「必須做！」）
  • ⬜ 長方形 → 資訊（「話你知」）
  • ⚠️ 兩大例外：讓路（倒三角）＋停車（八角形）＝ 限制標誌（禁制性）！

七、道路標記（路面標記）🛣️

🚨 最易混淆：標誌分三類，標記只分兩類！

《道路使用者守則》第八章嘅官方目錄：

官方分類 數目
交通標誌（signs） 發出指令的交通標誌、發出警告的交通標誌、發出提示的交通標誌 三類
道路標記（markings） 發出警告及提示的道路標記、發出指令的道路標記 兩類

⚠️ 陷阱：標記冇獨立嘅「警告」類或「提示」類——只有合併嘅「警告及提示」一類！ （「警告」同「提示」係標誌嘅分類，唔係標記嘅分類。）

官方標記分類 包括
發出警告及提示的道路標記 行車線界線、車路分界線、警告線、警告斜線標記、邊緣線、黃色橫條標記、行人過路處標記、慢駛、靠左駛、巴士線標記等
發出指令的道路標記 連續雙白線、斜條雙白線（切勿橫越或駛進斜線範圍）、「停車」線、黃色方格、之字線等

🚨 保護右轉車輛嘅白色斜線

《道路使用者守則》第五章（路口 → 轉右 → 從闊路轉右）原文：

「右轉線的路面上髹上斜線標記，保障右轉車輛的安全。」

同書第六章（雙白線）補充：

「路面上有白色斜線的部分，是用來分隔可能會有互相碰撞危險的車流，或用來保護轉右車輛的安全。不要駛越或駛入這範圍。」

分類：屬「發出警告及提示的道路標記」——即係警告及提示（兩者合一）。

🧠 考試問法：「右轉線路面上嘅斜線標記屬於邊一類？」 ✅ 答：警告及提示 ❌ 唔好揀「警告」或「提示」單獨一項——道路標記冇呢兩個獨立分類！ （之所以「警告」好易揀錯，係因為呢塊標記嘅官方名叫「警告斜線標記」。）

  • 呢種斜線標記係髹喺右轉行車線嘅路面上，等轉右嘅車可以停喺範圍內等候迎面車流出現安全空隙。
  • ⚠️ 無論如何：唔可以駛越或駛入呢個範圍。

🅰️ 自動繳費車輛行車線（快易通／Autotoll）

《道路使用者守則》原文：

「『自動繳費車輛行車線』標誌，展示於設有自動收費亭的行車線上方。在通往自動收費亭的行車線上，『自動繳費車輛行車線』引路標記會每隔一段路程重複髹在路面。備有有效標籤的車輛，方可使用自動繳費車輛行車線。」

🧠 記法：標誌上嘅圖案似個「A」字（Autotoll 快易通標誌）——冇有效標籤就唔好駛入呢條線。

五、記分制完整機制（三層行動！）

🔴 記分兩年滾動期係按干犯表列罪行的日期計算，唔係記分日期！

第一層：記滿8分（但少於15分）

運輸署署長發出「的士司機違例記分提示」——列明兩年內被記分紀錄，提醒再被記分嘅後果。

第二層：記滿10分

發出「強制修習的士服務改進課程通知」：

項目 詳情
限期 通知日期起計3個月內自費修習及完成
違反後果 無合理辯解未完成 → 第2級罰款$5,000+監禁1個月，仲要照上堂
完成獎勵 通過課程考試 → 減分：總分>3分減3分；總分≤3分全減

4種不獲減分情況（以完成課程當日計）： 1. 完成課程後未能通過考試 2. 根本冇任何分數（0分） 3. 已記總分15分或以上 4. 過去兩年內曾因完成課程而減過分

第三層：記滿15分

取消駕駛的士資格：首次停牌3個月，其後每次6個月。被取消資格後，相關罪行嘅分數記項全部註銷。

一、運輸署官方路線題（必做！）

🚨 官方例題一

由西灣河嘉亨灣 → 旺角拔萃男書院（正常交通，不考慮隧道費）

選項： - A. 經東區海底隧道、觀塘道、龍翔道及竹園道 - B. 經告士打道、紅磡海底隧道及公主道 ✅ - C. 經中環灣仔繞道、干諾道中、西區海底隧道、西九龍公路及麗翔道

🧠 解說：嘉亨灣（西灣河）是港島東，但拔萃男書院（旺角/九龍中）最直接是紅隧，非東隧。因為男書院在九龍中（旺角火車站附近），紅隧出口 → 公主道 → 窩打老道 → 亞皆老街最直接。

🚨 官方例題一變體

同一路程，但紅隧港島入口發生嚴重交通意外，哪條路線最直接？

  • A. 經東區海底隧道、觀塘道、龍翔道及竹園道 ✅
  • B. 經告士打道、紅磡海底隧道及公主道
  • C. 經中環灣仔繞道、干諾道中、西區海底隧道、西九龍公路及麗翔道

🧠 考點：紅隧受阻 → 改行東隧！呢條考你應變能力。

🚨 官方例題二

由荃灣悅來酒店 → 上環港澳碼頭（正常交通，不考慮隧道費）

選項： - A. 經青葵公路、西九龍公路及西區海底隧道 ✅ - B. 經青衣南橋、昂船洲大橋、青沙公路、西九龍公路及西區海底隧道 - C. 經龍翔道、竹園道、窩打老道、公主道、紅磡海底隧道及告士打道

🧠 解說：荃灣（新界西） → 上環（港島西） = 西隧！選項B繞去青衣南橋/昂船洲太迂迴，選項C繞去紅隧完全錯方向。

四、運輸署官方道路守則題

Q1：駛過水浸的街道後，你應怎樣做？ - 答案：立即試驗煞車系統的性能（道路使用者守則 P.87）

Q2：若用以豎立「不准停車」標誌的標誌杆為紅色，代表何時不准停車？ - 答案：上午七時至午夜十二時（守則 P.91）

🧠 考點：紅杆 = 7am-12am不准停車。非紅杆 = 24小時不准停車。呢個係好多人忽略嘅細節！

Q3：在薄霧天氣下看到工地標誌時，你應怎樣做？ - 答案：慢駛，與前車保持安全距離，並提防工程人員及車輛突然走近（守則 P.87-88）

六、易錯題精選（來自考生常見錯誤統計）

Q1：紅的能否進入大嶼山？ - 不能進入大嶼山南部禁區（如大澳、昂坪） - 但可經青嶼幹線到機場/東涌/迪士尼

Q2：綠的可否進入尖沙咀？ - 不可以。綠的營業範圍限新界，尖沙咀屬市區。

Q3：的士司機證必須放在哪裡？ - 車廂內乘客可見的位置

Q4：的士站排頭位的士，乘客上車前司機問目的地後拒載，是否合法？ - 不合法。這是典型的揀客行為。

Q5：的士在紅隧收費廣場，乘客付了隧道費後司機有冇責任給收據？ - 有。乘客要求的士收據，司機必須提供。

Q6：車輛駛過的士站時，能否在的士站範圍內停車上落客？ - 不可以。的士站是的士專用的。

Q7：的士車頂的「TAXI」燈箱在什麼狀態下必須亮著？ - 的士可供出租時（FOR HIRE狀態）

Q8：以下哪項是正確的行李收費？ - 放車尾箱的行李每件$6（不論大小） - 放車廂內長闊高總和超過140cm → 每件$6；≤140cm → 免費 - 輪椅、拐杖不收費 ✅（殘疾乘客賴以行動嘅輔助器具，不論大小及擺放位置；但傷殘乘客嘅其他行李仍須收費） - 嬰兒車按上述標準收費（冇豁免） - 手抱寵物不收費？錯！寵物每隻$5，不論手抱與否

Q9：的士計程錶上顯示的附加費（EXTRAS）包括什麼？ - 行李費、寵物費、隧道費等。不包括司機自定的任何費用。

Q10：下列哪項不是乘客的權利？ - 要求開/關空調 ✅（是權利） - 要求開/關窗 ✅（是權利） - 要求司機超速 ❌（不是權利！）

以下題目由剛考完真實考試嘅考生回報，屬乙部（道路使用者守則）範圍。呢啲全部係官方守則嘅明文規定，唔係陷阱題——但因為「感覺上唔似考點」而最易失分。

🧠 口訣：隧道三不——「不慢過25、不開高燈、不響號」。

涉及人身傷亡嘅意外現場 🚑

除非係為咗 拯救生命、滅火、處理其他緊急危險，否則切勿移動或干擾涉事車輛及現場任何物件。

⚠️ 「移開車免得阻路」係最常見嘅錯誤選項。

迴旋處 🔄

準備駛入迴旋處時，必須讓路給右方已喺迴旋處內嘅車輛（香港靠左行駛，迴旋處內順時針行車）。

路肩（Hard Shoulder）🛣️

主要供車輛發生故障或緊急事故時暫停，並供緊急車輛與公務巡邏使用。

⚠️ 陷阱選項：「分隔兩邊嘅車輛」——錯！

斜坡停車 🅿️

情況 正確做法
自動波・落斜泊車 先拉手掣／電子手掣鎖定，最後才入P波
手波・落斜泊車 入後波
上斜停車落車搬貨 拉緊手掣、熄火、手波入1波（自動波入P波）、前輪扭向右邊、後輪放車輪楔塊

保護轉右車輛嘅白色斜線標記 ➿

《道路使用者守則》原文：

「路面上有白色斜線的部分，是用來分隔可能會有互相碰撞危險的車流，或用來保護轉右車輛的安全。不要駛越或駛入這範圍。」

官方將「警告斜線標記」歸入發出警告及提示的道路標記（守則第八章）。

自動繳費車輛行車線 🅰️

「自動繳費車輛行車線」標誌（圖案似個「A」）展示喺設有自動收費亭嘅行車線上方；路面上會重複髹上引路標記。只有備有有效標籤嘅車輛方可使用。

傷殘乘客行李豁免範圍 ♿

小冊子原文：

「的士乘客如屬傷殘人士，他所攜帶的任何輪椅、拐杖或用作輔助行動的其他物件，不論大小及擺放位置，均可獲免費運載。」

⚠️ 豁免只限「賴以行動」嘅物件：

傷殘乘客攜帶嘅物品 收費？
輪椅、拐杖、輔助行動器具 ✅ 免費（不論大小、放車廂定車尾箱）
衣箱、旅行袋、背包等其他個人行李 ❌ 唔屬豁免，照按一般行李準則收費

🧠 「傷殘人士所有行李都免費」= 錯，係常見陷阱選項。

行李 140cm vs 180cm 📏

  • 擺放喺乘客車廂內嘅輕便個人手提行李，每件長、闊、高總和不超過140厘米 → 免費運載
  • ⚠️ 選項寫「180厘米」= 錯（正確係140厘米）

的士運載貨物限制 📦

「的士不得運載個人手提行李以外的貨物。個人手提行李，不得包括以下兩類：（1）屬危險或厭惡性質的貨物；（2）未經牢固包裝的貨物。」

網約車行李 🚗

網約車冇法定行李收費表——運載個人手提行李嘅規定同附加費一律由個別持牌平台決定；如涉及附加費，平台須於行程開始前讓乘客知悉。

🧠 對比：的士＝法定收費表；網約車＝平台自訂但要事先講清楚。

超車（扒頭）方向 ↔️

《道路使用者守則》原文：

「只可從右方超車。 切勿駛入左線超車，也不可利用路肩超車。」

「切記只可在前車的右面超車。」

一般規則 = 從右方超車；唯一例外係前車已打右燈準備轉彎 → 可以喺安全時從左方越過。

⚠️ 陷阱選項：「如不能從左方超車，才從右方超」——錯，掉轉咗。

⚠️ 題型提醒：否定式問題

實考有題目係反問，例如「以下哪項不正確？」、「以下哪項唔係……？」，選項亦可能出現「全部不正確」／「全部正確」。呢類題目一定要逐個選項獨立判斷，唔好見到熟悉字眼就撳。
